# Demon Hunt — 24i-3166

Python 3.10+. Missions 1–3 and tests use only the standard library.
The bonus chart and report generation require Pillow (`python -m pip install "Pillow>=10.1"`).
Keep `data/` next to `src/` (or `starter/` in the working project).

Run from any directory:

    python src/test_matchers.py
    python src/test_extended.py
    python src/mission1.py
    python src/mission2.py
    python src/mission3.py
    python src/mission4.py

In the working project replace `src/` with `DemonHunt_data/starter/`.
Bonus output is written to `output/bonus_chart.png` beside src/.
The report contains the measured run; timings vary by machine.
